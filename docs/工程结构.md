# 工程结构与维护约定

项目维护一套 Rust + Tauri + Vue 桌面应用。前端构建入口在仓库根目录，Rust crate 在 `src-tauri/`，所有桌面核心源码都归入该 crate。

```text
src/
  App.vue                    应用壳、导航及页面挂载
  views/                     代理、规则、日志、端口、SSH、DNS、云资源、设置、静态 HTTP 页面
  components/                公用设置区及全局对话框
  composables/
    useWorkspace.ts          应用会话、配置草稿、轮询及共用业务状态
    workspaceContext.ts      类型化的页面状态注入入口
    useLocalDns.ts           Hosts 编辑、分组及滚动同步
    useNetworkTools.ts       网络探测状态与操作
    useCloudResources.ts      云账号、安全组及受管规则状态与操作
  api/index.ts               IPC 调用封装和类型定义
  styles/                    基础样式、主题、探测页面与应用共用样式
src-tauri/
  src/
    main.rs                  可执行入口
    app.rs                   初始化、托盘、事件和命令注册
    state.rs                 应用共享状态
    types.rs                 IPC 响应类型
    config.rs                配置格式、兼容读取及持久化
    commands/                Tauri IPC 命令适配层
    services/                代理、SSH、云资源、Hosts、静态 HTTP 与网络服务
  examples/static-http-e2e.rs 真实 HTTP 端到端验证
  resources/geoip/           离线地址库
  vendor/                   现有本地第三方依赖
  gen/schemas/              Tauri 自动生成的权限 schema
  capabilities/             权限配置来源
  tauri.conf.json            应用与资源映射配置
scripts/                    开发启动、本机安装、源码归档、数据更新工具
.github/workflows/          CI 与 GitHub Release 构建
homebrew/Casks/              安装渠道元数据
```

页面通过 `workspaceContext` 获取同一组 ref，配置草稿、轮询及生命周期只由 `App.vue` 创建一次。功能 composable 接收明确的操作依赖；新增页面应优先把状态和行为放在相应功能模块中，避免重新堆入应用壳。对话框挂在应用壳中，共用样式限定于 `.app-shell`，以支持拆分页面后的同一套布局。

Rust 命令层负责 IPC 参数、异步任务与应用状态衔接，服务层负责具体协议和系统操作。跨模块类型仅使用 crate 可见性，不对外建立额外公共 API。既有配置目录、字段及 IPC 命令名称保持兼容。

`docs/使用说明.md` 是用户说明的唯一源文件；Tauri 将它映射成包内 `DomainEgress-使用说明.md`，本机开发 DMG 脚本也引用该文件。生成的 schema 不作为手工修改的来源。

## 验证

从仓库根目录执行：

```sh
npm ci
npm run build
cargo check --manifest-path src-tauri/Cargo.toml
cargo run --manifest-path src-tauri/Cargo.toml --example static-http-e2e -- /tmp/domain-egress-http-e2e
./scripts/package-source.sh /tmp/domain-egress-source
```

HTTP 验证输出可重复执行的资源目录、配置和 `report.json`，不修改用户配置，不新增单元测试。源码归档包含脚本、工作流、用户说明和第三方声明，排除依赖目录与构建产物，解压后可直接运行根目录构建命令。

正式 Release 安装包由 GitHub Actions 构建，通过 `gh run` 跟踪并用 `gh release` 发布。`npm run package` 和 `scripts/install-vue.sh` 仅供本机开发安装；脚本保留原名称以兼容已有调用。
